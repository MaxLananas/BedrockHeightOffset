# Hauteur logo

| File | Use |
|---|---|
| `hauteur-1024.png` | Master, full colour. Source of every other export. |
| `hauteur-512.png`, `hauteur-128.png`, `hauteur-32.png` | Colour exports for READMEs and listings. |
| `hauteur-mono-1024.png`, `hauteur-mono-512.png` | Monochrome glyph (black on transparent) for single-colour contexts. |

Regenerate the exports with `dev/release/export_logo.sh` (ImageMagick `convert` required).

The artwork was produced with a generative image model and selected by the maintainer. Check the
provenance and trademark status before using it outside this repository.
